# Using ShopIt

The app is named **ShopIt** on the window title, under the icon, in the Mac menu bar, in Windows Installed apps, and on the download files.

ShopIt is an open source app. It runs the same way on Windows, Mac, Android, and iOS. Use <img src="icons/shopping.png" width="22" height="22" alt=""> **Shopping** for what you need to buy, <img src="icons/pantry.png" width="22" height="22" alt=""> **Pantry** for what you already have, and <img src="icons/recipes.png" width="22" height="22" alt=""> **Recipes** for meals you plan to cook. When the shortest side is under 600, all four sit in the bottom bar and <img src="icons/settings.png" width="22" height="22" alt="Settings"> **Settings** is a full page. An Android phone or an iPhone stays in portrait. A larger window uses the side rail. Settings is a dialog when that window is at least 700 pixels wide, and a full page when it is narrower. Changing the size switches Settings while it is open. Close the page with the X at the top right or with Done.

The list menu is <img src="icons/more.png" width="22" height="22" alt="List options">.

## On each platform

Windows and Mac use the side rail. An Android phone and an iPhone use the bottom bar and stay in portrait. An Android tablet and an iPad use the side rail and can turn. The barcode button is on the phones and tablets.

## Shopping

<p align="center">
<img src="screenshots/search.png" alt="Search showing Milk already on the list, Oat milk from recent history, and catalog matches" width="720">
</p>

1. Open <img src="icons/shopping.png" width="22" height="22" alt=""> **Shopping**.
2. Create a list from the empty screen, or choose **New list** from <img src="icons/more.png" width="22" height="22" alt="List options">.
3. If you have more than one list, use the name at the top to switch between them.
4. Type in **Search or add an item**, then press Enter or tap <img src="icons/plus.png" width="22" height="22" alt="Add">. Use <img src="icons/pen.png" width="22" height="22" alt="Edit"> to set quantity, unit, category, price, tax, and a note before you add. On a phone or tablet, tap <img src="icons/scan.png" width="22" height="22" alt="Scan"> to add from a barcode instead of typing.
5. Tap an item to edit it. Check an item to move it into the cart.

From the cart you can uncheck everything (<img src="icons/uncheck.png" width="22" height="22" alt="Uncheck all">) or delete the checked items (<img src="icons/delete.png" width="22" height="22" alt="Delete all">).

The list menu covers a new list, move/copy, check and uncheck, categories, list settings, manage lists, CSV import and export, rename, and delete. **Rename this list** sits directly above **Delete this list**. Delete still asks you to confirm.

### Search

The field at the top looks through more than the catalog.

- **On this list** — the name is already on the open shopping list. Choosing it does not add a second copy. ShopIt shows that it is already there and moves the list to that item.
- **In pantry** — you already have it in the pantry. Choosing it does not add it to the shopping list.
- **Recent** — a name from History that is not already on this list or in the pantry. Choosing it adds the item again. <img src="icons/history.png" width="22" height="22" alt="History"> still opens the full history. The trash can beside a name there removes that recent only. The name stays searchable, and the item stays on any list that already has it.
- Catalog matches come after those. Press Enter or tap <img src="icons/plus.png" width="22" height="22" alt="Add"> to add something that is not already on the list or in the pantry.

With the field focused and empty, ShopIt shows up to six recent names so repeat groceries are one tap away.

A name that is not already in ShopIt is saved when you add it to a shopping list or to the pantry. The next search offers it with the built-in items. Adding that same name again does not store a second copy. A new name is filed under **Other**. To pick the category first, tap <img src="icons/pen.png" width="22" height="22" alt="Edit">, choose the category, then add. That category is what the name uses from then on. A pantry name is saved for search, and it does not appear under Recent. Recent is names you have added to a shopping list.

On a phone or tablet, <img src="icons/scan.png" width="22" height="22" alt="Scan"> sits next to Add. A known code adds that name. An unknown code looks up the package, then adds it. If there is no match, you name it; the code is kept so the next scan finds it. Windows and Mac have no scan button. A name added from a scan on the phone still appears on the computer through sync.

### List settings and categories

Categories are alphabetical on every list. A new category slots into that order on its own.

**List settings** controls whether items are grouped by category, whether new items are filed automatically, and whether empty category headers stay visible. The same screen is where you change tax for the whole list:

- **Use automatic tax rules** — each item follows the rate's rules again.
- **Mark all items taxable**
- **Mark all items not taxable**

Tap a category header to change its color. Manage the full category list from the list menu: add, recolor, or delete. There is no drag-to-reorder.

## Pantry

<p align="center">
<img src="screenshots/pantry.png" alt="Pantry with a Use soon strip for expired Milk and Yogurt expiring in two days" width="720">
</p>

Open <img src="icons/pantry.png" width="22" height="22" alt=""> **Pantry** for stock you already have. Add items the same way as on a shopping list, including the <img src="icons/plus.png" width="22" height="22" alt="Add"> button. An item can be **Low** or **Full**, or an exact amount, and it can include a place and an expiry date. On a phone or tablet, <img src="icons/scan.png" width="22" height="22" alt="Scan"> adds that product or increases the count if it is already there.

**Amounts**, in the list menu, sets every item on that pantry list at once. **Low or stocked** uses the Low and Full states. **Exact amounts** uses a number, such as 3 cans. **Apply to all** saves that choice for the items already there and for items you add later. One item can still be changed on its own.

**Use soon** appears at the top when something expires within the next seven days, or is already past its date. Each name says **today**, **tomorrow**, **in N days**, or **expired**.

**Move/Copy items** sends items between shopping lists and pantry lists—handy when you restock or finish something.

## Recipes

Open <img src="icons/recipes.png" width="22" height="22" alt=""> **Recipes** to save a meal.

1. Tap the new-recipe button and name it.
2. Set how many it serves.
3. Add ingredients by the same names you would search for in ShopIt, with an amount and unit.
4. **Add to list** asks which shopping list and how many servings to shop for. Amounts scale from the recipe. Names the pantry already covers are skipped; the rest go on the list. A new line's note says which recipe it is for.
5. **Cook** takes those amounts off the pantry. A full/low item is marked low.

Recipes use the same item names as Shopping and Pantry. They are not a second catalog.

## Sales tax

In **Settings** (<img src="icons/settings.png" width="22" height="22" alt="">), under sales tax (<img src="icons/tax.png" width="22" height="22" alt="">):

- Choose **No tax**, or add a saved rate.
- **Use my location** (<img src="icons/locate.png" width="22" height="22" alt="">) looks up a rate for where you are. In the US that lookup can use a Ziptax key saved in the same section. Nothing is sent until you tap the button.

Open Settings while Shopping is on screen to pick which rate that list uses. Each rate has its own tax rules (what is taxed). New items start taxable. You can turn tax off for one item in the item editor. To change every item on the list, open **List settings** from <img src="icons/more.png" width="22" height="22" alt="List options">.

## Sync between phone and computer

On both devices, open **Settings → Share lists**.

The summary at the top tells you which channels are on. Under it, each channel has its own line:

- **Wi-Fi: synced just now** (or a longer time), or **Wi-Fi: not synced yet.**
- **Cloud: synced just now**, or **Cloud: not synced yet.**

A failure stays on that channel. A successful Wi-Fi sync does not clear a cloud error, and the other way around. The same errors also show under **Devices** in Settings.

### Same Wi-Fi

Create a code on one device and type it on the other. The code is the key, so ShopIt does not send it over the network. Then turn on **Share on this Wi-Fi** on both devices and keep both apps open on the same network. Lists appear on the other device only after both have that code.

On a phone or a Mac, creating, joining, or scanning the code also turns **Share on this Wi-Fi** on. On Windows the computer is already on Wi-Fi, so the household code syncs over the internet and **Share on this Wi-Fi** stays off until you turn it on. Turn it on when the phone and the computer should also meet on the local network.

If Windows asks whether to allow ShopIt on private networks, choose allow. The phone cannot reach the computer on Wi-Fi until you do. That prompt is for **Share on this Wi-Fi**. The household code on Windows uses the connection the computer already has.

### Over the internet

Lists keep syncing when the phone is on mobile data, and when the Windows computer leaves **Share on this Wi-Fi** off. Both apps need an internet connection while they are open. They do not need to be nearby, and they do not need to be online at the exact same moment.

Pair them by hand:

1. On one device, tap **Create cloud code**. On Windows this leaves **Share on this Wi-Fi** off. On a phone or a Mac it turns that switch on.
2. On the other, enter that full code and tap **Join with code**. The same Windows rule applies.

Or use the QR code:

1. On Windows or Mac, tap **Show QR code**. On Windows, showing it leaves **Share on this Wi-Fi** off. On a Mac it turns that switch on.
2. On an iPhone or Android phone, tap **Scan QR code**. The scan joins the internet household from either computer and turns **Share on this Wi-Fi** on for the phone.

Both apps need an internet connection while they are open. They do not need to be nearby, and they do not need to be online at the exact same moment. Closing the app, or sending it to the background, publishes one last cloud snapshot.

List contents are encrypted with the secret half of the household code before they are stored. The cloud topic contains only the mailbox id, the part before the dot. The broker can store that encrypted copy. It does not receive the key, item names, prices, or notes. Leave cloud sync while online to delete this device's stored copy.

If you paired on an earlier build, leave the household on both devices and create a new code. Older codes and older cloud messages are ignored. What ShopIt sends is described in [Privacy](privacy.md).

### Lists with the same name

If both devices already have a shopping or pantry list with the same name, sync merges them and appends items. It does not create a second list that repeats what you already have.

## Appearance and About

In **Settings**, choose <img src="icons/monitor.png" width="22" height="22" alt=""> **System**, <img src="icons/sun.png" width="22" height="22" alt=""> **Light**, or <img src="icons/moon.png" width="22" height="22" alt=""> **Dark**.

**About** is the last section in Settings. It shows ShopIt, the version, a link to the source on GitHub, and **Privacy** and **Licenses**. Those open in place. They do not open another app.

## Releases

Each app update merged to `main` publishes from the version in `pubspec.yaml`: a Windows installer, an Android APK, and a Mac app. The Releases page keeps only the three newest builds. Changes that only touch this guide or the GitHub README do not publish a new build.
